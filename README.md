#status.php

##scopo dello script
verifica lo stato di un servizio e stampa a terminale se pronto

##Prerequisiti PHP
PHP8

##Comandi di esecuzione
###comando da terminale "php status.php"
Restituirà "Servizio demo: pronto
###comando da terminale "php status.php database"
Restituira "Servizio database: pronto"
